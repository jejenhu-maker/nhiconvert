健保申報資料去識別化轉 CSV 工具

把健保門診費用申報檔（TOTFA-xxxxx.zip）轉成去識別化的 CSV，方便交給 ChatGPT、Claude 等工具做資料分析。單一 HTML 檔，不用安裝，資料全程留在自己的電腦。

下載工具（HTML 檔）

請務必先把 HTML 檔下載到自己的電腦再開啟使用。申報檔含有病患個資，只能在診所自己的電腦上處理。

使用步驟

  1. 按「下載工具」，把 健保申報轉CSV工具.html 存到電腦（例如桌面）。
  2. 用 Microsoft Edge 或 Google Chrome 開啟這個 HTML 檔。
  3. 把申報檔（TOTFA-xxxxx.zip，可一次多個月份）拖進畫面，按「開始轉換」。
  4. 下載「就醫紀錄＋醫令明細」CSV，每個申報檔會產生一個同名 CSV。

身分證號會移除並改為隨機病人代碼，姓名改為「王○○」，出生日期只留年份，醫師身分證改為代碼。轉換過程完全在瀏覽器本機進行，不會上傳任何資料。

上課練習用假資料

沒有申報檔也能練習。下面的資料包是完全合成的假申報檔，格式與真實申報檔相同（TOTFA 的 tdata／ddata／pdata 結構），可以直接拖進工具裡轉換。

內含 TOTFA-11404、11405、11406、11504、11505、11506 共 6 個月份，每月約 1,000 筆就醫紀錄，另附 README（含可直接貼入 ChatGPT 的分析提示詞與診斷、藥碼對照）。課堂上先用 11505、11504、11405 三個月份。
