# 健保申報資料去識別化轉 CSV 工具

把台灣健保門診費用申報檔（TOTFA-xxxxx.zip 或解壓後的 TOTFA.xml）轉成去識別化的 CSV，方便交給 ChatGPT、Claude 等工具做資料分析。

- **單一 HTML 檔**，用 Edge 或 Chrome 直接開啟即可，不用安裝任何軟體，可離線使用。
- **資料不離開電腦**：解壓、解析、去識別化、產生 CSV 全部在瀏覽器本機完成。
- **每個申報檔各自輸出一個同名 CSV**（TOTFA-11401.zip → TOTFA-11401.csv）。

## 下載

- 下載頁：<https://jejenhu-maker.github.io/nhiconvert/>
- 或直接到 [Releases](https://github.com/JEJENHU-MAKER/nhiconvert/releases/latest) 下載 `健保申報轉CSV工具.html`

## 使用方式

1. 用 Microsoft Edge 或 Google Chrome 開啟 `健保申報轉CSV工具.html`。
2. 把申報檔（可一次拖入多個月份）拖進畫面。
3. 視需要調整去識別化設定，按「開始轉換」。
4. 下載結果：
   - **就醫紀錄＋醫令明細**（主要輸出）：每筆醫令一列，前段是該次就醫的 d 欄位，後段是醫令的 p 欄位。檔名為 `來源檔名.csv`。
   - 就醫紀錄：`來源檔名_就醫紀錄.csv`
   - 醫令明細：`來源檔名_醫令明細.csv`
   - 申報總表：`申報總表.csv`，每個申報檔一列
   - 全部打包成 zip（含說明.txt）

CSV 為 UTF-8 含 BOM，Excel 可直接開啟。欄位標題為「欄位代號 中文名稱」，依健保署「特約醫事服務機構門診醫療費用點數申報格式及填表說明（XML 檔案格式）」112.08.25 版。

## 去識別化處理

| 欄位 | 預設處理 | 其他選項 |
|---|---|---|
| d3 身分證統一編號 | 移除，改為隨機病人代碼 P00001…（同次轉檔內一致，無法反推） | 完全移除 |
| d49 姓名 | 保留姓氏，其餘以 ○ 取代（王○○） | 整欄移除 |
| d11、d45 出生年月日 | 只保留民國出生年 | 換算就醫時年齡／保留完整日期 |
| d30、d31、p16 醫事人員代號 | 改為代碼 DR01… | 保留原值／整欄移除 |

其他欄位（就醫日期、科別、診斷碼、藥品代號、點數等）原樣保留。

## 注意事項

- Excel 直接開啟 CSV 時，開頭為 0 的代號（例如就醫序號 0002）會被顯示成數字；需要保留時請用「資料 → 從文字/CSV 匯入」。
- 目前只針對門診格式（t1 為 10 或 30）標註中文欄位名稱；住院格式仍可轉換，但欄位標題只有代號。
- 需要支援 `DecompressionStream` 與 Big5 解碼的瀏覽器（Edge、Chrome 103 以上）。

## 開發與測試

`tests/` 內是用 Node 24 與 headless Chrome 跑的測試腳本，需要自行準備申報檔放在 `申報資料/`（此資料夾已在 .gitignore 排除，請勿上傳真實資料）。
